Display Mask - Android Studio project

1. Android Studio (Koala বা নতুন) খুলে File > Open > এই DisplayMask ফোল্ডার বেছে নিন।
2. Gradle sync শেষ হলে ফোন USB দিয়ে যুক্ত করুন (Developer options > USB debugging চালু)।
3. Run বাটন চাপুন। অথবা Build > Build APK(s) দিয়ে APK বানিয়ে ফোনে ইনস্টল করুন।
4. অ্যাপ খুলে "চালু করুন" চাপুন, অনুমতি দিন, তারপর স্লাইডার দিয়ে স্ট্রিপ দাগের উপর বসান।
